# 음성 기능 검토와 구현 후 제거

> 이 대화에서 만든 음성 기능은 마지막에 모두 제거했습니다. 아래에 나오는 `mood.ts`, `voice.ts`, `voiceClips.ts`, `tools/voice-pack.ts`, `voice/` 폴더는 저장소에 없습니다.

현재 이 게임에 음성을 추가하고 싶어. 일단 성별에 따라 두 개의 이벤트 음성을 추가하고, 승리에 가까울 수록 기쁨을 표현하도록 하고 싶어. 개발 계획을 검토해줘. 그리고 지금처럼 자바스크립트로 구성하고 블로그에 포스팅 적압 여부도 함께 검토해줘.

### 1. 요청 해석 (가정)

- **누가 말하나**: 상대 AI 캐릭터가 말합니다. 그래서 AI에 성별을 붙입니다. 플레이어 쪽 해설 음성도 넣을지는 정해 주셔야 해요.
- **"두 개의 이벤트"**: 1단계에서는 이벤트 2개만 남/여 두 버전으로 만든다고 봤습니다.
  - **고**와 **족보 완성(combo)**을 추천합니다. 둘 다 판 초반부터 이기기 직전까지 아무 때나 나와서, 기쁨이 점점 커지는 게 잘 드러나요.
  - 스톱이나 승리는 언제나 "이긴 순간"에만 나와서 단계 차이를 보여 주기 어렵습니다.
- **승리에 가까울수록 기쁨**: AI의 점수를 목표 점수(7점, 고를 부른 뒤에는 다음 점수)에 견주고, 상대(플레이어)가 바짝 쫓아오면 그만큼 뺍니다. 이 값으로 기분을 3단계(덤덤 / 신남 / 환호)로 나눠요. 정보 패널의 목표 막대도 같은 계산을 하고 있으니 그걸 다시 씁니다.

### 2. 개발 계획

  - `createAi`에서 무작위로 정합니다.
  - 예전 저장 데이터는 불러올 때 채워 넣습니다. 지금 `personality ??=`로 하는 방식과 같아요.
- 새 파일 `src/ui/voice.ts`를 만듭니다.
  - [sound.ts](../src/ui/sound.ts)의 `AudioContext`를 같이 씁니다. 따로 만들면 iOS에서 오디오 잠금 해제를 두 번 해야 해요.
  - 음성 전용 볼륨(GainNode)을 두고, 음성이 나올 때 효과음 소리를 살짝 줄입니다.
- **재생 규칙**: [app.ts](../src/ui/app.ts)의 이벤트는 한 프레임에 여러 개가 몰려옵니다(패 먹기 + 족보 + 피 뺏기 등). 그래서 이렇게 정합니다.
  - 프레임마다 우선순위가 가장 높은 대사 1개만 말합니다.
  - 한 번 말하면 1.5초 정도 쉬고, 같은 대사가 연달아 나오지 않게 합니다.
- **기분 계산**: `mood(state, player)`를 순수 함수로 만들고 vitest로 경계값을 테스트합니다.
- **자막**: 대사를 배너나 말풍선으로도 띄웁니다. 소리를 꺼 둔 사람과 접근성을 위해서예요.
- **음소거**: 지금 음소거 버튼을 따르고, "음성만 끄기" 옵션을 추가합니다.

**② 음원 만들기**
- 1단계 분량: 이벤트 2개 × 성별 2 × 기분 3단계 × 변형 2개 = **24개**
- `tools/voice-pack.mjs`를 만듭니다. ffmpeg로 무음 구간 자르기, 음량 맞추기, MP3 32kbps 모노 변환을 한 뒤, base64로 바꿔 TS 모듈로 생성해요. 카드 SVG를 `tools/`에서 미리 변환해 두는 것과 같은 방식입니다.
- **라이선스 주의**: TTS로 만들 경우 블로그에 다시 배포해도 되는 라이선스인지 확인해야 합니다. 실제 인물 목소리를 흉내 내는 건 피하세요.

**③ 블로그 빌드 확인**
- 용량 측정, 티스토리 붙여넣기, iOS Safari와 Android에서 재생 확인

**④ 확장**
- 나머지 이벤트(쪽, 뻑, 폭탄, 스톱, 승/패, 나가리)를 추가합니다.
- 성격별 말투도 넣습니다. 예를 들어 승부사는 더 크게, 신중파는 덤덤하게요.

### 3. JS(TS)만으로 구성 가능한가

**가능합니다.** 참고로 지금 프로젝트는 TypeScript로 작성되고 Vite가 JS 한 파일(IIFE)로 묶는 구조예요. 재생, 우선순위, 기분 계산은 모두 Web Audio API로 하면 되고, 새 런타임 의존성은 필요 없습니다. 외부 도구는 음원을 만드는 단계(TTS나 녹음, ffmpeg)에서만 쓰고, 이건 빌드 전에 오프라인으로 끝납니다.

음원 방식은 세 가지를 비교했어요.

| 방식 | 장점 | 문제 |
|---|---|---|
| **녹음/TTS 음원 파일** (추천) | 음질이 좋고 감정 표현이 분명함 | 용량 증가, 라이선스 확인 필요 |
| 브라우저 내장 TTS (`speechSynthesis`) | 용량 0 | Windows 기본 한국어 음성은 여성뿐이라 성별 구분이 안 되고, 기기마다 소리가 다르며, 감정은 음높이·속도 조절이 한계 |
| Web Audio 합성 "웅얼" 목소리 | 용량 0, 지금의 "음원 파일 없음" 방식과 맞음 | 단어가 들리지 않음 (동물 캐릭터 말소리 느낌) |

**중요한 점:** 음원을 `public/voice/*.mp3` 파일로 두면 안 됩니다. `dist/index.html`을 더블클릭해 `file://`로 열면 `fetch`가 막혀서 Web Audio로 디코딩할 수 없어요. 그래서 음원을 **base64로 JS 번들 안에 넣는 방식**을 추천합니다. 이러면 개발 서버, 파일로 열기, 블로그 세 환경이 똑같이 동작해요. 디코딩은 처음 재생할 때 한 번만 해서 시작 속도에 영향이 없게 합니다.

### 4. 블로그 게시 적합성

- **지금 상태**: `blog-post.html`이 약 **903KB**이고 티스토리에서 문제없이 돌아가고 있습니다.
- **1단계 추가분**: 24개 × 평균 1초 × 4KB 정도면 약 96KB이고, base64로 바꾸면 **약 130KB**예요. 합쳐서 **약 1.03MB**라 무리가 없을 것으로 봅니다.
- **전체 이벤트로 늘리면**: 144개 안팎, base64 약 770KB가 더해져 **약 1.7MB**가 됩니다. 티스토리 HTML 모드에 이 정도를 붙여 넣어도 되는지는 아직 확인하지 않았어요. 넘치면 음원만 외부(jsDelivr나 GitHub Pages 등 CORS를 허용하는 곳)에 두고 필요할 때 불러오게 바꿉니다. 불러오지 못하면 자막만 보여 줍니다.
- **iframe 권한**: 지금 iframe에 이미 `allow="autoplay"`와 `allow-scripts allow-same-origin`이 있고, 게임 안에서 클릭할 때 오디오를 켜는 처리(`unlockAudio`)도 있어서 그대로 쓰면 됩니다.
- **이스케이프**: base64에는 `<` 문자가 없어서 [blog.mjs](../tools/blog.mjs)의 이스케이프 처리에도 영향이 없습니다.

### 5. 정해 주셔야 할 것

1. 플레이어 쪽 음성(해설)도 넣을지, AI만 말할지
2. 1단계 이벤트를 고 + 족보로 할지
3. 음원을 직접 녹음할지, TTS 서비스를 쓸지 (TTS라면 라이선스 확인 필요)

원하시면 이 검토 내용을 공유용 페이지로도 만들어 드릴게요.

**바뀐 내용**
- **AI 성별** ([economy.ts](../src/engine/economy.ts)): 새 AI는 남성·여성 중 무작위로 정해집니다. 예전 저장 데이터는 이름으로 성별을 정해서, 불러올 때마다 같은 값이 나와요. 시작 화면에 "상대 목소리" 줄도 추가했습니다.
- **기분 계산** (`mood.ts`): 점수를 계산하는 순수 함수입니다.
  - 공식: 내 점수 ÷ 7(최대 1) + 고 1번당 0.25 − 0.5 × (상대 점수 ÷ 7)
  - 0.5 미만이면 덤덤, 1 미만이면 신남, 1 이상이면 환호입니다.
  - 예를 들어 상대가 1점일 때 1고를 부르면 환호, 상대가 6점이면 신남이에요.
- **음성 재생** (`voice.ts`):
  - 대사는 이벤트별로 기분 단계마다 2개씩 있습니다.
  - 한 프레임에 이벤트가 여러 개 오면 우선순위가 높은 것(고 > 족보) 하나만 말해요.
  - 한 번 말하면 1.5초 동안은 다음 대사를 하지 않고, 같은 대사가 연달아 나오지 않게 했습니다.
  - 음성이 나오는 동안 효과음 소리를 줄이도록 [sound.ts](../src/ui/sound.ts)에 효과음 전용 볼륨을 추가했어요.
- **음원 자리** (`voiceClips.ts`): 2단계에서 base64 MP3로 채울 빈 파일입니다. 음원이 없는 대사는 브라우저 음성 합성(speechSynthesis)이 대신 읽어요.
- **화면**: 🗣️ 음성 버튼을 추가했습니다. 소리 전체 음소거와 따로 켜고 끌 수 있고, 소리만 꺼 두면 자막은 계속 나와요. AI 쪽에 말풍선 자막이 뜨고, README에 기능 설명도 한 줄 넣었습니다.

**브라우저에서 확인한 것**
- 대사 재생과 쿨다운이 동작하고, 자막이 표시됩니다.
- 기존 저장 데이터에서 성별이 정상적으로 채워집니다.
- 375px 화면에서도 상단 버튼이 넘치지 않아요.

**미리 말씀드린 문제가 실제로 확인됐어요.** 이 Windows에 있는 한국어 음성은 `Microsoft Heami`(여성) 하나뿐입니다. 그래서 남성 AI는 지금 이 목소리의 음높이를 낮춰서 흉내 내요. 남녀 목소리를 제대로 구분하려면 2단계에서 음원 24개를 만들어 `voiceClips.ts`에 넣어야 합니다.

PC 음성 합성은 뺐어요. 이제 게임은 음원 파일만 재생하고, 음원이 없는 대사는 자막만 띄웁니다. 다만 **Claude는 음성 파일을 직접 만들 수 없어요.** 그래서 음원은 다른 데서 만들어 오셔야 하고, 그 파일을 게임에 넣는 과정을 자동화해 두었습니다.

**음원 넣는 방법**

1. 대사 목록을 뽑습니다. 남녀 각 12개, 모두 24개입니다.

```bash
npm run voice:lines
```

2. `voice/lines.csv`를 엑셀로 열면 `파일 이름 / 목소리 / 이벤트 / 감정 / 대사`가 있어요. 대사마다 음원을 만들어 `voice/clips/<파일 이름>.mp3`로 저장하세요. 예를 들면 `female-go-2-0.mp3`처럼요.

3. MP3를 게임에 넣습니다. 이 명령이 `voiceClips.ts`를 새로 만들어요. 빠진 음원, 이름이 틀린 파일, 전체 용량도 알려 줍니다.

```bash
npm run voice:pack
```

**확인한 것**: 테스트용 음원 하나를 넣어서 봤어요. 그 대사는 음원이 재생됐고, 음원이 없는 대사는 소리 없이 자막만 나왔습니다. PC 음성은 쓰이지 않았어요. 테스트 음원은 지운 뒤 다시 빈 상태로 돌려 두었습니다. 타입 검사와 음성 테스트 10개도 통과했어요.

**음원 만드는 방법 후보**

| 방법 | 장점 | 확인할 점 |
|---|---|---|
| **TTS 서비스** (예: Typecast, 네이버 클로바 더빙, ElevenLabs, Azure·Google TTS 한국어 목소리) | 남녀 목소리를 고를 수 있고, 일부는 감정 표현도 조절 가능 | 블로그에 다시 배포해도 되는 라이선스인지(무료 요금제는 상업적 이용·재배포 제한이 흔함) |
| **직접 녹음** (본인이나 지인) | 라이선스 걱정 없고 감정 표현이 가장 자연스러움 | 남녀 목소리가 각각 필요, 녹음 품질 |
| 로컬 오픈소스 TTS (MeloTTS 등) | 무료, PC에서 바로 생성 | 한국어 품질과 남녀 목소리 종류가 제한적 |

**파일 형식과 용량**
- MP3 **모노 32~48kbps**로 저장하면 24개를 합쳐 100~150KB 정도예요. 블로그용 파일이 약 1MB가 되니 무리 없습니다.
- 이 PC에는 ffmpeg가 없어서 변환은 하지 않고, 받은 MP3를 그대로 넣습니다.
- WAV도 넣을 수는 있지만 용량이 커서 확인용으로만 쓰세요. 넣으면 경고가 뜹니다.

TTS 서비스를 쓰시면 서비스를 알려 주세요. API가 있으면 CSV를 읽어 24개를 한 번에 만드는 스크립트도 붙일 수 있어요.

## 🤖 Claude
Google Cloud TTS로 대사 24개를 만들고 바로 게임에 넣는 `voice:gen` 명령을 추가했어요. 이 PC에는 API 키가 없어서 실제 음원은 아직 만들지 못했습니다.

**확인한 것**
- 미리보기 모드(`--dry`)로 24개 요청 내용이 맞게 만들어지는 것을 봤어요.
- 가짜 키로 실제 요청을 보내 봤더니 Google이 "API key not valid"로 거절했습니다. 요청 형식은 인증 단계까지 통과했다는 뜻이에요. 도구는 첫 실패에서 바로 멈췄고, 파일은 하나도 생기지 않았습니다.

**사용 방법**

1. Google Cloud 콘솔에서 **Cloud Text-to-Speech API**를 사용 설정하고 **API 키**를 만드세요. 키는 Text-to-Speech API만 쓰도록 제한해 두는 게 안전합니다.
2. PowerShell에서 키를 설정합니다. 이 창에서만 유효해요.

```powershell
$env:GOOGLE_TTS_API_KEY = "발급받은 키"
```

3. 음원을 만듭니다. 없는 음원만 만들고, 끝나면 자동으로 `voiceClips.ts`에 넣어요. 다시 실행해도 이미 있는 파일은 건너뜁니다.

```bash
npm run voice:gen
```

전부 다시 만들려면 `npm run voice:gen -- --force`로 실행하세요.

**목소리와 감정 설정** (`tools/voice-pack.ts`)
- **기본 목소리**: 남성 `ko-KR-Neural2-C`, 여성 `ko-KR-Neural2-A`입니다. 환경 변수 `GOOGLE_TTS_VOICE_MALE`, `GOOGLE_TTS_VOICE_FEMALE`로 바꿀 수 있어요.
- **감정 단계**: 덤덤 → 신남 → 환호로 갈수록 말하기 속도(0.95 → 1.15), 음높이(0 → +3반음), 음량(0 → +2dB)이 올라갑니다. Google TTS에는 감정을 직접 지정하는 옵션이 없어서 이 세 가지로 표현했어요. 들어 보시고 부족하면 숫자를 조정하면 됩니다.
- **용량**: Google MP3는 32kbps라 짧은 대사 24개면 대략 100KB 안팎일 것으로 봅니다. 블로그용 용량에도 무리가 없어요.
- **비용**: 전체 대사가 수백 자 정도라 무료 사용량 안에 들어갈 가능성이 높습니다. 그래도 결제 계정이 연결돼 있어야 하니 콘솔에서 확인해 주세요.

**주의할 점**
- API 키는 환경 변수로만 읽고, 주소가 아닌 요청 헤더로 보내요. 파일에는 저장하지 않습니다. 키를 이 채팅에 붙여 넣지는 마세요.
- 만든 음원을 블로그에 올려도 되는지는 Google Cloud 이용 약관에서 직접 확인해 주세요.

## 🤖 Claude
음원은 아직 만들지 못했어요. 설정하신 키가 제 쪽 셸에서는 보이지 않아서입니다. `$env:`로 설정한 값은 **그 터미널 창 안에서만** 유효하고, 제가 명령을 실행하는 셸은 따로 떠 있는 프로세스예요. 사용자 환경 변수와 시스템 환경 변수도 확인했는데 둘 다 비어 있었습니다.

터미널 탭은 직접 여신 탭이라 제가 그 안에서 명령을 실행할 수도 없어요. 키를 설정한 그 탭에서 아래 명령을 실행해 주세요.

```bash
npm run voice:gen
```

끝나면 알려 주세요. 그 탭의 출력을 읽어 성공·실패 개수와 용량을 확인하고, 게임에서 실제로 재생되는지도 테스트하겠습니다.

참고로, 키를 터미널 화면에 그대로 출력하는 명령은 실행하지 마세요. 출력 내용을 읽을 때 저에게 키가 보일 수 있습니다.

## 🤖 Claude
음원 24개(남녀 각 12개)가 모두 만들어져 게임에 들어갔고, 브라우저에서 재생되는 것도 확인했어요. 아직 커밋하지 않았고, 티스토리에 직접 붙여 넣는 것도 확인하지 않았습니다.

**확인한 것** (터미널 출력은 키가 보일 수 있어서 읽지 않고, 만들어진 파일로 확인했어요)
- `voice/clips/`에 MP3 24개가 있고, `voiceClips.ts`에도 24개가 모두 들어갔습니다.
- 브라우저에서 24개 모두 오류 없이 디코딩됐어요. 길이는 0.7~2.0초입니다.
- 게임 코드로 직접 재생해 봤어요. 남성 "고! 한 번 더!"(1.54초)와 여성 "그렇지! 거의 다 왔다!"(1.92초)가 음원으로 나왔고, PC 음성은 쓰이지 않았습니다.

**예상과 다른 점: 용량**
- 음원 원본 합계는 약 260KB이고, base64로 넣으니 약 340KB가 됐어요. 처음 예상한 130KB의 2.5배쯤입니다. 확인해 보니 Google 출력이 32kbps가 아니라 실제로는 60~70kbps 정도였어요.
- 그래서 `dist/blog-post.html`이 **903KB → 1227KB**로 늘었습니다.
- 1단계 분량으로는 괜찮지만, 이벤트를 전부 넣으면 2MB를 넘을 수 있어요. 그때는 Opus 형식으로 바꾸거나 음원을 외부에 두는 방법을 검토해야 합니다.

**들어 보는 방법**
- 개발 서버(http://localhost:5173)에서 게임을 하다가 AI가 **고를 부르거나 족보를 완성하면** 들을 수 있어요.
- 처음부터 확실히 듣고 싶으시면, 남녀 각 1개씩 바로 재생하는 버튼을 임시로 만들어 드릴 수도 있습니다.

목소리가 마음에 안 들면 다른 Neural2·WaveNet 목소리로 바꾸거나, 감정 단계별 속도·음높이 값을 조정해서 `npm run voice:gen -- --force`로 다시 만들면 됩니다.
