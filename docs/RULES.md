# 맞고(2인 고스톱) 규칙 정리

> 개발용 규칙 명세. 지역이나 서비스(한게임, 넷마블 등)마다 다른 부분은 **[변형]**으로 표시했다.
> 이런 부분은 설정값(`RuleConfig`)으로 빼 두는 것을 권장한다.

---

## 1. 화투 구성 (48장 + 보너스패)

12개월 × 4장 = 48장. 카드 종류는 **광 / 열끗(동물) / 띠(단) / 피**의 네 가지다.

| 월 | 이름 | 광 | 열끗 | 띠 | 피 |
|---|---|---|---|---|---|
| 1 | 송학 | 학 광 | - | 홍단 | 피 ×2 |
| 2 | 매조 | - | 꾀꼬리 (고도리) | 홍단 | 피 ×2 |
| 3 | 벚꽃 | 벚꽃 광 | - | 홍단 | 피 ×2 |
| 4 | 흑싸리 | - | 두견새 (고도리) | 초단 | 피 ×2 |
| 5 | 난초 | - | 다리 | 초단 | 피 ×2 |
| 6 | 모란 | - | 나비 | 청단 | 피 ×2 |
| 7 | 홍싸리 | - | 멧돼지 | 초단 | 피 ×2 |
| 8 | 공산 | 달 광 | 기러기 (고도리) | - | 피 ×2 |
| 9 | 국진 | - | 술잔 (**쌍피로 전환 가능**) | 청단 | 피 ×2 |
| 10 | 단풍 | - | 사슴 | 청단 | 피 ×2 |
| 11 | 오동(똥) | 봉황 광 | - | - | 피 ×2, **쌍피** ×1 |
| 12 | 비 | **비광** | 제비 | 비띠 (단 조합 없음) | **쌍피** ×1 |

- 합계: 광 5, 열끗 9, 띠 10, 피 24장(쌍피 2장 포함)
- **쌍피**는 피 2장으로 계산한다.
- **보너스패 (확정)**: **2피 2장 + 3피 1장**을 추가해 총 **51장**을 쓴다.
  - 카드 중앙에 큰 숫자 `2` 또는 `3`을 표시하고, 배경은 **빨간색 계열**로 한다. 11월·12월의 기본 쌍피는 일반 디자인 그대로 둔다.
  - **손에서 낼 때**: 즉시 내 피로 가져오고, 더미에서 1장을 손으로 보충한 뒤 이어서 1장을 낸다.
  - **더미에서 뒤집혀 나올 때**: 즉시 내 피로 가져오고, 1장을 더 뒤집는다.
  - **배분 때 바닥에 깔릴 때**: 선이 가져가고, 더미에서 1장을 바닥에 보충한다.
  - **피를 빼앗길 때**: 일반 피 → 쌍피 → 보너스패 순서로 내준다.

## 2. 게임 준비 (맞고)

1. **선 정하기**: 첫 판은 패를 한 장씩 뽑아 정한다. 낮에는 높은 월, 밤에는 낮은 월이 선이다(밤일낮장). 다음 판부터는 **직전 판 승자가 선**이고, 나가리가 나면 선을 유지한다.
2. **패 돌리기**: 각자 **10장**, 바닥에 **8장**을 깔고, 남은 **23장**이 더미(뒷패)가 된다. 보너스패 3장이 포함된 51장 기준이다.
3. **바닥 특수 상황**
   - 바닥에 같은 월이 4장 깔리면 → 재배분.
   - 바닥에 같은 월이 3장 깔리면 → 나중에 그 월의 4번째 패로 먹는 사람이 3장을 모두 가져간다.
   - 바닥에 보너스패가 깔리면 → 선이 가져가고 더미에서 1장을 보충한다.
4. **총통**: 손에 같은 월 4장을 받으면 즉시 승리한다. **[변형]** 10점으로 치거나 7점으로 친다. 승리 대신 계속 진행하는 옵션을 두기도 한다.

## 3. 턴 진행

한 턴은 **① 손패 내기 → ② 더미 뒤집기 → ③ 획득 처리** 순서다.

### ① 손패 내기
- 바닥에 같은 월 패가 **1장** 있으면 그 패와 짝지어 놓는다.
- 같은 월 패가 **2장** 있으면 그중 **1장을 골라** 짝짓는다. 열끗인지 피인지 같은 차이 때문에 선택이 중요하다.
- 같은 월 패가 **3장** 있으면 4장을 모두 먹는다. 바닥에 놓여 있던 뻑을 먹는 경우다.
- 같은 월 패가 **없으면** 바닥에 그냥 놓는다.

### ② 더미 맨 위 패 뒤집기
- 뒤집은 패도 ①과 같은 방식으로 바닥과 짝을 맞춘다.

### ③ 획득 처리와 특수 이벤트

| 이벤트 | 조건 | 효과 |
|---|---|---|
| **쪽** | 낸 패가 짝 없이 바닥에 놓였는데, 뒤집은 패가 그 패와 같은 월 | 2장 획득 + 상대 피 1장 |
| **뻑(설사)** | 낸 패로 바닥 1장과 짝지었는데, 뒤집은 패도 같은 월 | 3장 모두 바닥에 남음(못 먹음) |
| **뻑 먹기** | 바닥의 뻑(같은 월 3장)을 4번째 패로 먹음 | 4장 획득 + 상대 피 1장. **자뻑**(자기가 싼 뻑)은 피 2장 |
| **따닥** | 바닥에 같은 월 2장이 있는데, 낸 패와 뒤집은 패가 모두 그 월 | 4장 획득 + 상대 피 1장 |
| **쓸(싹쓸이)** | 턴이 끝났을 때 바닥이 비어 있음 | 상대 피 1장 |
| **첫뻑 / 연뻑 / 삼연뻑** | 첫 턴에 뻑, 2연속 뻑, 3연속 뻑 | **[변형]** 첫뻑·연뻑은 상대에게 칩이나 점수를 받는다. **삼연뻑은 즉시 승리**(보통 7점 또는 10점) |

- 상대에게서 피를 빼앗을 때는 일반 피를 먼저 가져가고, 일반 피가 없으면 쌍피를 가져간다. **[변형]** 쌍피를 주면 1장을 돌려받기도 한다.
- 마지막 턴(더미가 비는 턴)의 쓸이나 쪽은 피를 빼앗지 않는 규칙도 있다. **[변형]**

### 흔들기 / 폭탄
- **흔들기**: 손에 같은 월 3장이 있고 바닥에 그 월이 없을 때, 그중 1장을 내면서 3장을 공개할 수 있다. 이기면 **점수 ×2**.
- **폭탄**: 손에 같은 월 3장이 있고 바닥에 같은 월 1장이 있을 때, 3장을 한꺼번에 내서 4장을 모두 먹는다. 상대 피 1장을 받고 **점수 ×2**(흔들기로 간주).
  - 폭탄으로 손패가 2장 줄었기 때문에 **빈 패(도탄) 2장**을 받는다. 빈 패를 내는 턴에는 손패를 내지 않고 더미만 뒤집는다.
- 흔들기와 폭탄은 횟수만큼 중첩된다. 2회면 ×4.

## 4. 점수 계산

| 분류 | 조건 | 점수 |
|---|---|---|
| **광** | 3광 (비광 없음) | 3점 |
| | 3광 (비광 포함) | 2점 |
| | 4광 | 4점 |
| | 5광 | 15점 |
| **열끗** | 5장 | 1점, 1장 늘 때마다 +1 |
| | **고도리** (2·4·8월 새) | +5점 |
| **띠** | 5장 | 1점, 1장 늘 때마다 +1 |
| | **홍단** (1·2·3월) | +3점 |
| | **청단** (6·9·10월) | +3점 |
| | **초단** (4·5·7월) | +3점 |
| **피** | 10장 | 1점, 1장 늘 때마다 +1 (쌍피 = 2장) |

- **9월 열끗(국진)**은 열끗과 쌍피 중 하나로 쓸 수 있다. 구현할 때는 점수 계산 시점마다 **유리한 쪽을 자동 선택**하는 방식이 간단하다. 실제 게임은 획득하는 순간 선택하게 한다.
- 12월 비띠는 띠 장수에만 들어가고 홍단·청단·초단 조합에는 포함되지 않는다.

## 5. 고 / 스톱

- 내 점수가 **7점 이상**이 되면(맞고 기준) **고** 또는 **스톱**을 선언한다. 3인 고스톱은 3점이다.
- **스톱**: 판이 끝나고 정산한다.
- **고**: 게임을 계속한다. 이후에 **직전 선언 때보다 점수가 더 올라야** 다시 고나 스톱을 선언할 수 있다.
- 고 보너스:

| 고 횟수 | 보너스 |
|---|---|
| 1고 | +1점 |
| 2고 | +2점 |
| 3고 | (점수 +3) ×2 |
| 4고 | ×4 |
| 5고 | ×8 … 이후 1고마다 ×2 |

  **[변형]** 3고부터 +점수 없이 배수만 적용하는 곳도 있다.
- **고박(독박)**: 고를 선언한 사람이 이후에 지면, 상대 점수를 **×2**로 물어 준다.
- **나가리(무승부, 확정)**: 더미와 손패가 모두 떨어질 때까지 두 플레이어 모두 스톱하지 못한 경우다.
  - 고를 선언한 뒤 점수를 더 올리지 못하고 끝난 경우도 나가리로 처리한다. 이때 고박은 적용하지 않는다.
  - 다음 판 승자의 **최종 점수 ×2**를 적용한다. 나가리가 연속으로 나면 **누적**해서 ×2, ×4, ×8…로 커진다. 승부가 나면 배수는 ×1로 초기화된다.
  - 나가리가 나면 선은 그대로 유지한다.
- 마지막 턴에 점수가 나서 고를 이어갈 수 없으면 **자동 스톱**으로 승리 처리한다. 나가리가 아니다.

## 6. 박 (패자에게 적용되는 배수)

| 박 | 조건 | 배수 |
|---|---|---|
| **피박** | 승자가 피로 점수를 냈고, 패자의 피가 **7장 미만** **[변형: 5장 이하, 6장 이하 / 0장 면제]** | ×2 |
| **광박** | 승자가 광으로 점수를 냈고, 패자의 광이 **0장** | ×2 |
| **멍박** | 승자의 열끗이 **7장 이상** **[변형: 미적용인 곳 많음]** | ×2 |
| **고박** | 패자가 고를 선언한 상태였음 | ×2 |

- 모든 배수는 곱해진다.
- 패자가 박 조건을 피하는 면박 규칙(예: 피박 상태인데 쌍피를 가지고 있음)은 서비스마다 다르다.

## 7. 최종 정산 공식

```
기본점 = 광 + 열끗(+고도리) + 띠(+홍/청/초단) + 피
고 적용 = 기본점 + 고 보너스(1·2고) → 3고 이상이면 배수 적용
최종점 = 고 적용 점수
        × 2^(흔들기 + 폭탄 횟수)
        × (피박 ? 2 : 1) × (광박 ? 2 : 1) × (멍박 ? 2 : 1) × (고박 ? 2 : 1)
        × 2^(연속 나가리 횟수)
금액 = 최종점 × 점수당 금액   (점수당 금액은 9절 참고)
```

## 9. 하우스 룰 (프로젝트 확정 사항)

### 게임 주체
- **플레이어(나)** 1명과 **AI 플레이어** 1명이 겨룬다.

### 레벨
- 플레이어(나)의 초기 레벨은 **1**이다.
- AI 플레이어가 파산하면 플레이어 레벨이 **+1** 오른다.

### 금액 (단위: 원, KRW)
- 플레이어(나)의 초기 금액은 **50,000원**이다.
- **점수당 금액 = (floor(레벨 / 10) + 1) × 100원**

| 레벨 | 1~9 | 10~19 | 20~29 | … |
|---|---|---|---|---|
| 점수당 금액 | 100원 | 200원 | 300원 | … |

- **지급**: 스톱으로 승패가 나면 **승자의 최종 점수 × 점수당 금액**을 패자가 승자에게 준다.
  - 패자의 보유금이 부족하면 가진 금액까지만 지급하고, 잔액이 **0원**이 되면 파산한다.

### AI 플레이어 생성
- **생성 시점**: 새 게임을 시작할 때, 또는 AI가 파산해 퇴장했을 때.
- **생성 시 금액**
  - 첫 AI: **50,000원**
  - 이후 AI: `이전 AI의 생성 시 금액 × (1 + r)`. `r`은 0~0.4 사이의 무작위 값이고, 결과는 100원 단위로 반올림한다.
  - 기준은 이전 AI의 **생성 시 금액**이다. 파산 시점의 금액은 0원이므로 기준이 될 수 없다.

### 플레이어(나) 파산
- 게임 오버 처리 후 **완전 초기화**한다. 레벨 1, 금액 50,000원, 새 AI(50,000원)로 다시 시작한다.

### 자동 저장
- **저장 시점**
  - 승패가 결정될 때 (스톱, 자동 스톱, 총통, 삼연뻑 포함)
  - 나가리가 났을 때
  - 파산 처리가 끝났을 때
- **저장 항목**: 플레이어 금액, 레벨, AI 금액, AI 생성 시 금액, 직전 승자(다음 판 선), 연속 나가리 횟수.
- **판 도중 종료 방지**: 판을 시작할 때 `inProgress = true`를 저장해 둔다. 다음 실행 때 이 값이 남아 있으면 비정상 종료로 보고 플레이어 **기권패**로 처리한다. 지급할 점수는 7점이다.
- 다음 실행 때 저장 데이터를 불러와 이어서 플레이한다.

### 구현에서 정한 세부 기준
- 승리 기준점은 7점이다.
- 피박은 패자의 피가 7장 미만일 때 적용한다. 0장도 면제하지 않는다.
- 멍박은 승자의 열끗이 7장 이상일 때 적용한다.
- 총통과 삼연뻑은 즉시 10점으로 승리한다. 나가리 배수만 곱한다.
- 첫뻑·연뻑에 대한 별도 보상은 없다. 연출만 한다.
- 마지막 턴의 싹쓸이는 피를 빼앗지 않는다. 쪽과 따닥은 빼앗는다.
- 첫 판의 선은 무작위로 정한다.
- 국진(9월 열끗)은 점수가 높아지는 쪽으로 자동 계산한다. 패자의 피박 판정에서는 피로 계산해 준다.

### 애니메이션과 소리
카드 이미지는 SVG/CSS로 직접 그리고, 효과음은 Web Audio API로 합성한다(저작권 문제 회피).

| 이벤트 | 연출 |
|---|---|
| 손패를 바닥에 냄 | 손 → 바닥 이동, 놓는 소리 |
| 더미 맨 위 패를 뒤집음 | 뒤집기(flip) 후 바닥으로 이동 |
| 따닥 / 쪽 / 쓸 | 큰 글자 팝업과 효과음 |
| 상대 피를 가져옴 | 상대 피 영역 → 내 피 영역 이동 |
| 뻑 | 흔들림 효과, 뻑 글자 표시 |
| 고 / 스톱 | 화면 중앙 대형 팝업과 음성 효과 |
| 족보 달성 (고도리, 홍단, 청단, 초단, 3·4·5광) | 해당 패 강조와 족보 이름 표시 |
| 추가 연출 | 흔들기, 폭탄, 총통, 보너스패 획득, 피박·광박 결과, 나가리, 레벨업, AI 파산과 새 AI 등장 |

## 8. 개발 메모

- **상태 머신 단계**: `DEAL → (총통 체크) → TURN[손패 선택 → (바닥 2장 중 선택) → 뒤집기 → (바닥 2장 중 선택) → 이벤트 처리 → 점수 체크 → (고/스톱 선택)] → END/정산`
- **플레이어 입력이 필요한 지점**: 낼 패 선택, 흔들기 여부, 바닥 2장 중 선택(손패용·뒤집은 패용 각각), 고/스톱, 9월 열끗 사용처.
  모두 같은 인터페이스(`chooseAction(state, options)`)로 추상화하면 사람과 AI 플레이어를 똑같이 다룰 수 있다.
- **AI가 보는 정보**: 자기 손패, 바닥, 양측 획득 패, 남은 더미 장수. 상대 손패와 더미 순서는 숨긴다(비공개 정보 게임).
  - 1단계: 규칙 기반 휴리스틱. 광·고도리·단 우선, 상대 족보 저지, 뻑 회피 등.
  - 2단계: 보이지 않는 패를 무작위로 배치해 여러 번 시뮬레이션하는 **몬테카를로(Determinization + MCTS)**.
- **[변형] 항목**은 모두 `RuleConfig`로 분리한다. 예: 승리 기준점, 피박 기준 장수, 멍박 사용 여부, 보너스패 사용 여부, 총통·삼연뻑 점수, 고 배수 방식.
- 셔플 시드를 받을 수 있게 만들어 두면 재현 가능한 테스트와 버그 리플레이에 유리하다.
